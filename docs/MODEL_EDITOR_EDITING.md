# Проверка повседневного редактирования MineMod Studio 0.3.2

3 октября 2026 года. Продолжение [проверки 0.3.1](MODEL_EDITOR_POLISH.md): числовой ввод, сохранение, история и одновременные ручные/агентные изменения. Новых зависимостей нет. Формат проекта, trusted packs, Java-код и JAR не менялись.

## Найденные и исправленные ошибки

| Сценарий | Исправленное поведение |
| --- | --- |
| Изменить размер и сразу нажать «Сохранить» мышью | Клик сохраняется при завершении ввода. Запись ожидает применения нового размера; E2E сравнивает файл с текущей геометрией. |
| Ввести недопустимый размер и нажать Ctrl+S или «Сохранить как…» | Ошибка остаётся видимой. Сохранение после отказа команды не выполняется, прежний файл остаётся побайтно прежним. |
| Получить запоздавшее уведомление worker после сохранения или смены проекта | Последовательность ответов защищает состояние интерфейса: старый ответ не возвращает прежний документ или признак несохранённых изменений даже при одинаковой ревизии. |
| Изменить сохранённый документ и сделать undo обратно к сохранённому содержимому | Документ снова считается сохранённым; закрытие не показывает лишний диалог. Redo возвращает признак изменений. Номер ревизии по-прежнему растёт. |

Если агент обновил проект, пока человек вводил размер, устаревшая правка отклоняется с `STALE_REVISION`; связанное с ней сохранение также отменяется. Это проверено через настоящий HTTP MCP клиент. В компактной мастерской сведения о плотности пикселей и отступе UV доступны также в подсказке строки UV.

## Windows CI

В `.github/workflows/phase-0.yml` добавлена job `studio-windows` на `windows-2022`: frozen install, lint/typecheck, переносимые пакеты, HTTP MCP, чистая упаковка и проверка итогового EXE в скрытых окнах. Отчёты, снимки и inventory лицензий публикуются как test artifacts; пользовательские и временные клиентские конфигурации в upload не входят. Actions закреплены полными commit SHA.

Команды пакетов и packaged E2E проверены локально на Windows; синтаксис YAML проверен парсером Prettier. Job на GitHub **не запускалась**. Проверки Linux compiler/runtime продолжают выполняться в отдельных существующих jobs и не ослаблены ради Windows.

## Границы результата

Общий Windows workspace ранее дал 13 PASS / 6 FAIL из-за POSIX mode/ownership и Linux-only runner; детали и исходный лог сохранены в [отчёте 0.3.1](MODEL_EDITOR_POLISH.md#ограничения-общего-прогона). Установленный Codex проверяется на уровне реальных MCP tool calls через app-server, Claude — регистрации и HTTP health. Самостоятельные model turns и tool calls Claude не запускались. Авторизация и глобальные настройки пользователя не менялись. Clean Fabric build, GameTests, dedicated server, интеграция ресурсов в ModSpec/JAR и художественная/игровая приёмка этим этапом не подтверждены.

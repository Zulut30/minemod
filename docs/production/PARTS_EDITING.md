# Имена, группы и защита частей

Пункт 025, в работе. Studio 0.12.0 даёт ручное именование и сборку выбранных кубов в часть. Часть — существующая плоская semantic group с постоянным ID и списком cube IDs. Вложенные папки и новая схема проекта не добавляются.

## Ручная работа

Выберите часть или куб в дереве. Ctrl/Shift добавляет выбранные кубы к выделению или убирает уже выбранные; тот же режим поддержан в 3D. В свойствах задайте понятное имя. «Сохранить имя» меняет label существующей целой части с сохранением ID и замка. «Собрать в часть» создаёт новый ID, переносит выбранные cube IDs и удаляет только опустевшие исходные группы. Выбор отдельного куба позволяет отделить его в новую часть.

Геометрия, PNG-план и UV при изменении структуры сохраняются точно. Куб по-прежнему принадлежит ровно одной части. Сохранение, варианты и undo/redo используют прежний Project v2. Новых dependencies или изменения trusted inputs нет.

Имя ограничено 80 символами; пустое имя отклоняется. Ввод остаётся draft до явной кнопки. При одновременной правке агента stale rename/group получает CAS conflict с сохранением текста. Пользователь сверяет сцену и явно обновляет привязку к revision. Смена проекта или выделения создаёт новый draft.

## Скрытие и закрепление

Кнопка глаза управляет видимостью текущей рабочей сцены и не изменяет документ. Скрытие не запрещает агенту правку: для защиты нужен замок. View-state не сохраняется в файл и сбрасывается при новом проекте; IDs удалённых частей очищаются из списка скрытых после структурной правки. Полная скрытая модель не исключается из экспорта или agent review.

Закрепление сохраняется в проекте и запрещает agent transform/paint/delete/UV и другие адресные операции. Человек может переименовать закреплённую часть, сохранив её ID и замок. Перегруппировка любых кубов из закреплённой части требует сначала явно снять замок. Агент не получает `renamePart`/`groupPart`/`lock`: они исключены из опубликованной schema, legacy обход отклоняется, core повторяет permission check.

После группировки агент читает новые IDs и названия через `studio_project_inspect` и создаёт новый proposal. Правка незакреплённой гарды не меняет закреплённую рукоять. Замки не являются художественной оценкой и не заменяют user approval.

## Проверки

Core suite проверил неправильные IDs/имена/targets, duplicate targets и ID collisions, human-only permissions, отказ перегруппировки закреплённой рукояти, atomic rollback и stale revision. Проверены exact geometry/texture invariants, persistence/undo/redo и реальная адресная agent transform рядом с неизменной закреплённой рукоятью.

Focused hidden packaged GUI проверяет именование закреплённой детали, multiselect двух частей, группировку без потери рисунка, undo/redo, реальные PNG скрытия и точное восстановление viewport, public MCP, отказ agent rename/regroup/unlock, stale draft/rebind и exact save/restart. Первый harness использовал revision до undo/redo, поэтому закономерно получил CAS conflict вместо ожидаемого lock denial; лог сохранён. Исправленный harness перечитывает revision после истории. Это ошибка проверки, а не разрешённый обход CAS.

Полный hosted пакет по новому source ещё ожидается. [Точное evidence](evidence/parts-025.json). Функция помогает адресно описывать детали модели; улучшение художественного качества и приёмка в Minecraft не измерены.

Дополнительная проверка изображения сначала захватила атлас из первого canvas и ожидаемо не увидела скрытие рукояти. После выбора actual 3D viewport скрытие изменило PNG, а возврат восстановил точные pixels. Оба лога сохранены; геометрия/документ не подменялись.

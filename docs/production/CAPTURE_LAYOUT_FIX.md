# Полная модель в возвращённом PNG обзора

Корректирующая проверка roadmap 023/037, Studio 0.14.1. Локальный результат PASS. Hosted проверка commit `2e8e99a` завершена: Windows package со всеми 17 подотчётами, control-plane, NeoForge и production Fabric 1.20.1/Java 17 с client smoke прошли. Весь workflow остаётся failure из-за отдельного checksum-сбоя legacy Fabric 26.2. [Evidence](evidence/capture-layout-023.json) сохраняет отрицательный результат старого пакета отдельно от исправленного.

## Воспроизведение

В собственном скрытом пакете Studio 0.14.0 при Windows DPI 175% первый `studio_model_review` возвращал обрезанный pommel. Камера была рассчитана для размера 3D-панелей до появления трёх миниатюр. Их загрузка меняла высоту панелей, а ResizeObserver и GPU ещё не успевали пересчитать кадр к capture. Более поздний `capturePage` уже показывал целый предмет; проверка такого позднего снимка пропускала дефект.

Фактический PNG старого пакета в отрицательной проверке имеет нижнее поле 0 px в передней панели. PNG после исправления показывает обе оконечности; поля сверху и снизу во всех четырёх панелях не меньше 19 px. Это техническая проверка кадрирования контрольного оружия, а не оценка его художественного качества.

## Изменение

Для каждой миниатюры обзорной доски выделяется постоянный контейнер 64×64 ещё до появления изображения. Размер 3D-панелей при загрузке не меняется. Формат PNG, камера, модель, рисунок и закрытые MCP-инструменты сохраняют свои контракты; новый dependency не добавлен.

Скрытый packaged helper декодирует именно PNG ответа `studio_model_review` и анализирует яркие пиксели модели внутри каждой из четырёх canvas-областей. Для этого контрольного предмета обязательны видимые пиксели и поле не меньше 4 px со всех сторон. Один и тот же assertion отклоняет неизменённый пакет 0.14.0 и принимает 0.14.1. Это локальный regression witness одного известного дефекта, не универсальный художественный score или доказательство отсутствия clipping у любого проекта.

Дополнительно сохраняются проверки компактного GUI, native 32/64 px, сохранности ручной камеры/сцены, адресного ремонта, а полный hosted suite подтверждается отдельно для точного commit.

Поведение `useFrame` и demand-rendering сверено через Context7 `/pmndrs/react-three-fiber` и [официальные hooks](https://r3f.docs.pmnd.rs/api/hooks); hidden capture — по [Electron webContents](https://www.electronjs.org/docs/latest/api/web-contents#contentscapturepagerect-opts). Приёмка художественного результата и работа authored assets в Minecraft остаются отдельными gates.

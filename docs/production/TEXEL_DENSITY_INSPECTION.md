# Диагностика масштаба пикселей

Studio 0.22 добавляет измерение UV для человека и агента. Пункт 051 остаётся открыт: численный отчёт не подтверждает, что соседние поверхности выглядят согласованно. Авторская текстура «Листа», её визуальная оценка и игровые виды ещё не приняты. Ни UV, ни рисунок не меняются при измерении.

## Ручная проверка

В «Текстура / UV» раскройте «Масштаб пикселей» и задайте целые `пикс./блок` и `допуск, %` из задания. Начальные 16/10 являются значениями панели, а не автоматически подтверждённым ArtSpec. При выделении проверяются все шесть граней выбранных кубов; без выделения — вся модель. Для одного куба показаны шесть граней, для нескольких — четыре с наибольшим отклонением. Сводка охватывает всю выборку. Раскрытая панель прокручивается, сохраняя доступ к атласу и UV-кнопкам в компактном окне.

Плотность измеряется отдельно по двум направлениям грани: `UV pixels / (cube.size + 2 × inflate) × 16`. Для ±Z это X/Y, для ±X — Z/Y, для ±Y — X/Z. Rigid cube rotation и отражения UV сохраняют длины. Старый числовой UV hint теперь также учитывает inflate. Скрытые и внутренние грани измеряются наравне с остальными; occlusion и художественная значимость не анализируются.

Положительный целый диапазон пикселей в пределах допуска проверяется отдельно. Его отсутствие не является разрешённым исключением, а ближайшее положительное число не означает соблюдение профиля. Отдельный счётчик показывает, что минимальное подходящее число превышает текущую ширину/высоту атласа; он не обещает возможность упаковки всех прямоугольников вместе. При численном overflow density равна `null`, направление считается неизмеримым и не получает положительный результат. Размеры атласа, геометрия и допуск не подстраиваются автоматически.

## MCP

Новый read-only инструмент `studio_uv_inspect` увеличивает inventory до 11 инструментов; mutation schema и человеческие полномочия не расширены:

```json
{
  "projectId": "<actual UUID>",
  "expectedRevision": 0,
  "profile": { "pixelsPerBlock": 16, "tolerancePercent": 10 },
  "cubeIds": ["blade"]
}
```

`cubeIds` можно опустить для всей сцены. Strict schema ограничивает profile: 1–256 пикс./блок, 0–100% допуска; IDs — максимум 256, без неизвестных и повторных кубов. CAS и обычная авторизация/очередь MCP сохраняются. Максимум отчёта — 1536 граней / 3072 направления; проверена укладываемость в фиксированный response limit 2097152 bytes. Output обозначает profile как `caller-supplied-not-ArtSpec-verified`, а artistic acceptance — `requires-human-review`. Инструмент не удостоверяет внешний ArtSpec, не создаёт approval и не добавляет shell/eval.

Перед paint/UV-правкой агент читает актуальные IDs/revision и выбирает профиль из задания, рассматривает отчёт и реальные captures. Невозможный integer scale требует решения о конструкции или заранее описанной политике поверхности, а не молчаливого повышения допуска. Перепаковка 055 сохраняет текущий масштаб, поэтому сама не устраняет это отклонение.

## Проверенные границы

Core проверяет шесть направлений несимметричного куба, зеркальные UV, inflate, допустимое вращение, inclusive tolerance, невозможность integer scale/atlas capacity, subnormal overflow с конечным JSON, пустую сцену, 256 кубов и malformed input. HTTP MCP проверяет read-only state, strict profile/IDs и stale revision. Focused packaged-сценарий использует куб 2×4×8 с inflate=1 и отражёнными UV 4×8: ожидаемая плотность северной грани 16 × 21.333… пикс./блок, восемь из двенадцати направлений вне профиля 16/10. UI ввод, старый hint, точные project/file bytes и неизменность истории проверены отдельно.

Первый компактный снимок показал clipping атласа/UV-кнопок раскрытой диагностикой. Отрицательная wheel-проверка сохранилась в `output/playwright/texel-density-051-800a8398/texel-density/failure.json`; после исправления прокрутки focused-сценарий прошёл в `output/playwright/texel-density-051-f331606e/texel-density/report.json`. Полный локальный набор (`studio-packaged-5dbade1f`) и hosted Windows (`studio-packaged-1028e0af`) прошли все 23 сценария на source `b2791f3d39b716eef53efb2ba1456d89e08ade21`. [Evidence](evidence/texel-density-051.json) связывает Git blobs, локальный ASAR, отчёты и оригинальные PNG; CI artifact не содержит ASAR, поэтому его побайтовое совпадение с локальным пакетом не утверждается.

[CI 37465942001](https://github.com/Zulut30/minemod/actions/runs/37465942001) завершён: control-plane, Windows, production Fabric 1.20.1 / Java 17, NeoForge и auxiliary client прошли. Production проверяет два обязательных harness GameTests, dedicated-server/client readiness с остановкой nonce, шесть generated source files и точный JAR. Это проверка инфраструктуры и инструмента, без художественной или authored Minecraft приёмки. Общий workflow имеет `failure`: legacy Fabric 26.2 отклонил checksum `minecraft-common-043a8b3edf`; ожидаемый и фактический SHA-256 сохранены, причина не установлена, verification policy не ослаблялась.

Read-only измерение неизменённого нейтрального C «Листа» (`9b8e63ce…`) сопоставляет scaffold UV с ArtSpec 16 пикс./блок / 10%: все 354 грани имеют по 8×8 пикселей при разных физических размерах. Для 564 из 708 направлений положительный integer UV не помещается в этот допуск. Это диагноз scaffolding перед авторской текстурой, а не готовая оценка ArtSpec или основание менять его thresholds. Исходник, PNG и ArtSpec остаются прежними.

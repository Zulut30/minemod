# Тёмная тема, клавиатура и масштаб

Пункт 022, в работе. Studio 0.12.1 исправляет потерянный фокус числовых полей, публикует состояние переключателей режима и объявляет ошибки через один ARIA alert. Точное доказательство: [accessibility-022.json](evidence/accessibility-022.json).

## Реализованные изменения

Числовое поле получило рамку на всей группе оси. При Tab она остаётся видимой на тёмном фоне; фокус других кнопок и полей сохраняет прежнее оформление. Четыре переключателя режима имеют `aria-pressed`, активным остаётся ровно один. Обычный статус использует polite live region, ошибка — assertive alert без вложенного второго status. Фактическую работу конкретного screen reader это не подтверждает.

Вне фокуса размер показывает до шести десятичных знаков, при входе восстанавливается полное исходное число и выделяется для замены. Форматирование не округляет геометрию, не создаёт undo и не меняет файл. Focus transition синхронно обновляет DOM через имеющийся React DOM `flushSync` только в обработчике фокуса: следующая browser input operation не должна дописать ввод к старому числу. Правило и ограничения проверены по [официальной документации React](https://react.dev/reference/react-dom/flushSync) и Context7; новой зависимости нет.

## Фактическая матрица

| Среда | Масштаб дисплея | Размер окна, DIP | Что проверено |
|---|---|---|---|
| Текущая Windows 11 x64 | 175%, zoom 1 | 1120×760 и 1440×960 | Скрытый packaged EXE: Tab/Enter, рамка, error alert, доступность прокручиваемых полей, отсутствие внешнего overflow |
| Hosted Windows | Будет записан из actual display | Те же два размера | Новый source suite ещё ожидается |

Это границы проверки текущего candidate, а не новые обещания всех разрешений или Windows builds. Приложение и тесты не меняют масштаб/настройки мониторов пользователя. Forced zoom, переход между мониторами, другой физический DPI и полный screen-reader workflow пока не проверены.

Восемь выбранных важных элементов проверены по фактическим foreground/background: заголовок документа, подсказка, заголовок панели, имя части, основная кнопка, выбранный режим, ошибка и числовое поле. Каждый элемент обязан существовать; пропуск не считается PASS. Для мелкого текста установлен минимум 4,5:1 по [W3C contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). В этой выборке минимум 7,83:1. Контраст disabled controls, всей палитры состояния предупреждений и hover во всех режимах, а также WCAG соответствие всего приложения этим результатом не присваиваются.

## Регрессии и пределы приёмки

Первоначальная рамка 2px в текущем DPI давала 1,71429 CSS px; итоговая 3px даёт 2,85714 CSS px. Ошибки ранних helpers и локальной формы чисел сохранены в логах. Проверка геометрии обнаружила дописывание числа после фокуса; исправление восстанавливает полный ввод до browser event и выделяет его. Ожидаемые размеры, snap tolerances и CAS проверки не ослаблены. Добавлен assertion фактически введённого значения, чтобы следующая такая регрессия имела точную диагностику.

Повтор прежней geometry suite подтвердил snap, pivot с полной точностью, Escape, rotations и экспорт, неизменные texture bytes, шесть undo/redo, точное восстановление исходного PNG и отказ stale input. Отдельная accessibility suite проверила отказ BOUNDS без изменения точного документа. Окна оставались скрытыми и закрылись штатно; пользовательский workspace не использовался.

Пункт остаётся открытым до достаточной матрицы важных состояний и масштабов. Локальный technical PASS не является художественной приёмкой модели, пользовательским пилотом, общей WCAG сертификацией или подтверждением Minecraft assets.

## Расширенная проверка состояний

Следующий candidate 0.12.1 также объявляет выбор части/куба, ракурса, кисти, сетки, каркаса и замка; раскрытие части получает `aria-expanded`. Keyboard Enter действительно переключает ракурсы и четыре инструмента рисования, раскрывает/скрывает часть и меняет замок с возвратом. Режимы просмотра и рисования не меняют документ.

В 11 actual UI states проверен весь найденный видимый непрозрачный текст: normal/selected, export hover, четыре режима, ошибка имени, autosave warning, saved clean и оба состояния замка. Каждый state содержит минимум 20 текстовых узлов; неизвестный цвет или отсутствие текста отклоняется. Минимальный ratio — 5,86:1. Disabled/opacity controls и текст внутри raster/canvas исключены явно; это не общий WCAG сертификат.

Проверка создаёт недоступность recovery только в своём временном каталоге, переименовывает часть клавиатурой, видит настоящий warning и сохраняет точный проект через Ctrl+S. Geometry и texture plan совпадают с первоначальными, замок после переключений восстановлен. Native save dialog подставляет только собственный путь. Первый assertion ошибочно предположил, что пример уже закреплён; теперь исходный state читается из actual document, а оба lock states проверяются реальными действиями. Hosted expanded source suite ожидается.
